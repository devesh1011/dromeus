# Dromeus v0.2.0

Decentralized federated learning with NoLoCo over AXL. Each participant trains on
its own data and exchanges updates with peers. Your application owns the model,
loss, optimizer, and data loader.

## Included

- NoLoCo outer optimization with fixed, even-sized groups of 4 to 16 workers.
- Top-k sparsification, int8 quantization, and outer-gradient error feedback.
- Multi-chunk transfer with acknowledgments, bounded retries, and integrity checks.
- Custom PyTorch training through local workload factories, optional evaluation,
  and checkpoint state callbacks.
- Per-node training logs and reproducible benchmark reports.

## Install

Use Python 3.12 and install the wheel from this release:

```sh
uv pip install https://github.com/devesh1011/dromeus/releases/download/v0.2.0/dromeus-0.2.0-py3-none-any.whl
```

Run your application with `--factory your_package:prepare_training`, or pass
`prepare_training` to `run_node`. See the [application guide](https://github.com/devesh1011/dromeus/blob/v0.2.0/examples/README.md)
for configuration and state callbacks. NoLoCo is the default; D-PSGD can be selected
explicitly for compatibility.

## Benchmarks

The report covers GroupNorm ResNet-18 on IID CIFAR-10 at 4, 8, and 16 NVIDIA A10G
workers: nine compressed AXL runs, six NCCL references, and one uncompressed AXL
comparison. Every accepted run completed 500 outer rounds and 25,000 local steps
per worker. All six matched final-accuracy comparisons differ by less than 0.38
percentage points. Nominal Dromeus transfer-protocol bytes were reduced by 5.06x.

The report includes learning curves, compression measurements, regional deployment
conditions, and artifact availability. [Full logs and evidence](https://github.com/devesh1011/dromeus/tree/v0.2.0/benchmarks/results/m2)
remain in the repository.
