# Dromeus v0.2.0: NoLoCo over AXL

Dromeus supports decentralized federated learning with NoLoCo peer updates over
AXL. Each participant trains on its own data. The application supplies the model,
loss, optimizer, and data loader; Dromeus handles group formation, peer exchange,
and committed training state.

## Changes since v0.1.0

- NoLoCo is the default decentralized algorithm. Explicit D-PSGD remains available
  for compatibility and controls.
- Fixed, even-sized groups of 4 to 16 workers exchange outer gradients and slow
  weights through deterministic peer matching.
- Top-k sparsification, int8 quantization, and outer-gradient error feedback reduce
  update traffic. Identity transport remains available for codec comparisons.
- Multi-chunk transfer uses acknowledgments, bounded retries, integrity checks,
  and a sliding window over AXL.
- Applications own their training code and local data. The PyTorch adapter supports
  custom models, optional named evaluation metrics, and application state callbacks.
- Reported benchmark evidence includes nine compressed AXL runs, six NCCL
  references, and one four-worker identity-codec ablation.

## Migration

The node entry point requires a local workload factory. Pass `--factory
your_package:prepare_training` to the CLI, or supply `prepare_training` when
calling `run_node`. The factory owns the model, local optimizer, loss, data, and
continuation state. See the [application guide](https://github.com/devesh1011/dromeus/blob/main/examples/README.md).

NoLoCo drafts resolve an omitted algorithm ID to `noloco`. Select `dpsgd`
explicitly when retaining the earlier algorithm. Group settings and codecs still
need to be declared. Obsolete manifest v1/v2 inputs are rejected; the frozen M2
benchmark uses v3 and application-owned training uses v4.

CIFAR workloads live in the benchmark code, outside the runtime wheel. Use the
repository checkout for benchmark commands. Existing hash-bound benchmark inputs
and captured source snapshots remain unchanged.

## Packages and evidence

Python 3.12 is required. The wheel and source distribution contain the runtime;
they exclude benchmark logs, model weights, AWS captures, and development tooling.
The source distribution can be rebuilt into a wheel with `uv build`.

The review bundle contains the technical report, machine-readable metrics,
figures, frozen configuration, and accepted-run reports. Full logs and additional
provenance remain in the [benchmark evidence tree](https://github.com/devesh1011/dromeus/tree/main/benchmarks/results/m2).
The initial-checkpoint archive supplies the three hash-bound, untrained model
initializations for the benchmark. The review bundle is not a self-contained
training reproduction archive.

## Limits

The GPU results cover GroupNorm ResNet-18 on IID CIFAR-10 with 500 outer rounds and
25,000 local steps per worker. Different regional topologies prevent a normalized
AXL-versus-NCCL speed claim. The historical 40% pilot's transfer-time result does
not establish a controlled speed reduction for the final 45% configuration.

Membership is fixed for a run. Automatic distributed restart, secure aggregation,
differential privacy, and pipeline parallelism are not included. General non-IID
or language-model convergence is not established by the reported experiments.

Some checkpoint binaries and raw captures were pruned; retained hashes do not
restore those files. Private checkpoint access and current artifact availability
are described in the evidence index. Internal run acceptance is distinct from
Gensyn's final milestone acceptance.
