# NoLoCo pinned-upstream outer-step fixture

`noloco_upstream_outer_step_v1.json` is generated by executing `outer_step()` from
the clean, pinned `gensyn-ai/noloco` commit recorded in the fixture. It uses two CPU
Gloo processes, tiny FP32 tensors, unequal slow and fast weights, and nonzero prior
outer momentum. It does not use C4, a language model, or a GPU.

Regenerate it from a clean checkout:

```bash
uv run python scripts/generate_noloco_upstream_fixture.py \
  --upstream-root /path/to/noloco
```

The generator rejects a different upstream commit or local changes to the source
file. The parity test compares Dromeus's identity-codec outer gradient, momentum,
and next slow weights with the frozen output using the tolerance recorded in JSON.
